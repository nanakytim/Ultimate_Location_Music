# CONFIGURATION
### This Mod is highly customisable to your taste:
- **DIFFERENT SONGS:** Add a single song or many! You can have a unique location music for Illagers, the Nether, and mob variants (such as Husk and Stray). Finally, you can have a unique musique for each vanilla Boss, and for Raids! Each of those can be disabled **or** play the normal location music instead.
- **VOLUME:** Set the volume of each unique song to your taste. **There is also an Underwater Pitch modifier to add variation, that you can switch off.**
- **FADE:** Add Fade in/out to the location music!
- **DETECTION SYSTEM:** Pick between "Targetting Player" and Radius. The first one will play location music whenever a monster is actively chasing you. The second will play it if you're within a monster's radius.
- **RADIUS:** When Detection is by Radius, decide how big the Radius is for each Monster type.

**_NOTE: By default, Creepers only play music within a small Radius, to keep the vanilla element of surprise!_**

### ALL location MUSIC TYPES:
These are ordered by priority. The higher priority will always play and force a fade-out on the others. For example, if you're fighting spiders and a Pillager Patrol spawns, the music will fade into the Illagers theme song!

This Mod provides default music. You can replace them with your own by overwriting the songs with a Resource Pack! The path for each file is as follows: assets\location_music\sounds\
1. **Bosses:** location_enderdragon.ogg | location_wither.ogg | location_warden.ogg
2. **Raid:** location_raid.ogg
3. **Illagers:** location_illager.ogg
4. **Nether:** location_nether.ogg
5. **Normal & Variant:** location_music.ogg | location_variant.ogg

It's fully client-side, no dependencies. Have fun!
